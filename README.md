# Abocado / Yusuke Portfolio

Rails・Flutterを中心とした開発経験を紹介する、日英対応のポートフォリオです。Next.js 15 / React 19 / TypeScript / Tailwind CSS 3を使用します。

## ローカル起動

Node.js 22.13以降を使用します。

```sh
npm ci
npm run dev
```

日本語は `/ja`、英語は `/en`。言語指定のないアクセスはブラウザの言語を判定し、日本語を既定値にします。

## 構成

| 場所                              | 内容                                                                   |
| --------------------------------- | ---------------------------------------------------------------------- |
| `src/content/work.ts`             | 実績・担当内容・日英の説明                                             |
| `src/content/career.ts`           | 開発以前を含む経歴・日英の説明                                         |
| `src/content/site.ts`             | サイトの文章・対応分野・技術ノートのURL                                |
| `src/components/`                 | 共通ヘッダー、言語切替、実績の表示と絞り込み                           |
| `src/app/[locale]/`               | トップ、実績一覧・詳細、プロフィール、サービス、技術ノート、問い合わせ |
| `src/app/globals.css`             | 色、余白、文字、レスポンシブ表示、動きを減らす設定                     |
| `src/middleware.ts` / `src/i18n/` | 言語のルーティング                                                     |

実績は本人の公開プロフィールと確認された内容をもとに整理しています。未確認の顧客名、担当責任、数値成果、サンプル作品は追加しません。Rails・Flutterの業務開発は匿名で記載し、案件名・画面・ソースの公開範囲は別途確認します。

2026-10-12に本人が日英の実画面を確認し、公開とGitHubでのバージョン管理を依頼した改修をv2.1.0として管理します。画像案の番号v12と製品リリース番号を分けています。オフホワイト `#fbf8f2`（JA `#fbf9f5`）、濃い青 `#0b2c34`、くすんだ赤 `#a63e0d`を使います。構成・本人の実績・英訳・外部リンクは既存のVercel側情報を維持します。

- トップは匿名の手元が設計ノートを書く生成画像を使い、本人の写真ではないことを表示します。`public/images/v12/`に原寸参照PNG3枚を保存し、`ReferenceImageRegion.tsx`と`reference-artwork.ts`で文字のない部分だけを表示します。ページ全体を画像にせず、本文・見出し・リンクはReact/HTMLです。
- 新しい断面ロゴを`BrandMark.tsx`で共用し、同じSVGから16〜256pxのfaviconを生成します。ロゴ資料全体や参考画面をそのまま公開ページへ貼り付けません。
- 求人マッチングとメッセージ業務には承認された説明用画像を使い、実案件の画面ではないことを表示します。残り4作品は新しいアート未提供のまま、架空の顧客画面を加えません。旧`WorkVisual.tsx`は既存ファイルとして保持しています。
- ホームはhero、サービス、代表2作品、仕事の進め方、相談の順。重複する紹介を短い同義要約と詳細リンクに整理し、実績一覧・作品詳細・プロフィールの正式情報を残します。
- `src/content/approved/`の取得した原文JSONと表示用adapterから日英コピーを参照します。AIは実装の補助に使い、人が要件整理・設計・レビュー・動作確認を担う方針です。成果や速度の保証ではありません。
- 日英切替は現在パスを保持。全画面メニューはEscape・フォーカス循環・背景inert・履歴・resizeに対応します。問い合わせの受付は変更しません。
- Next.js・React・TypeScript構成と依存バージョンは維持しています。リリースは新規の`v2.1.0`タグと`CHANGELOG.md`で記録し、既存タグを移動しません。

直接の参照画像は3ルートで、残り21ルートと他の幅は同じdesign systemから派生しています。正式font・logo/vector・独立したclean画像が未提供のため、書体・icon形状・画像mask・詳細の本文量に差が残ります。画像の元CSS viewportは不明で、1024×1536の比較は推定canvas、厳密なpixel一致ではありません。最終版の実200% / reduced-motionはブラウザ操作の制約により未検証です。

開発経験は6つの紹介枠に整理しています。2資料の自動化経験は同一案件か未確認のため1つの枠で担当内容を紹介し、案件数とは数えません。求人マッチングとメッセージング支援も含め、カードゲームは無償の依頼制作と明記しています。プロフィールには元Gitの14件の経歴と現在の取り組みを残しています。資料間で異なる期間や不明な開始日は「確認中」として、日付を推測しません。

## 検証

```sh
npm run typecheck
npm run lint
npm run build
```

既存の自動テストはありません。画面では日英のルート、実績の絞り込み、詳細表示、スマホのメニュー、Escape操作、言語切替、404、横スクロール、キーボードのフォーカスを確認します。

GitHub Actionsの`Portfolio CI`はpush / pull requestでNode22、`npm ci`、lint、build、typecheckを実行します。存在しない単体test suiteを合格とは扱いません。公開時はmain・新規タグ・CI・Vercel commitと既存aliasを照合し、公開先の主要動線も確認します。

## 問い合わせ

公開する連絡方法が未確定の間は、受付準備中と表示します。`src/config/contact.ts`で受付を停止しているため、既存のSMTP設定があっても送信しません。フォームの公開を承認された後にこの停止設定を変更し、実行環境で次の値を設定します。

- `CONTACT_FORM_ENABLED=true`
- `GMAIL_USER`
- `GMAIL_PASS`
- `CONTACT_TO`

認証値をソースや公開される環境変数へ保存しないでください。送信先のメールアドレスもソースには含めません。受付停止中はAPIが503を返します。有効化後はSMTP設定がない場合に503、入力不正に400を返します。

送信の有効化前にNodemailerの依存更新とテスト用SMTPでの検証を行います。

## 公開

既存のVercelプロジェクトとGitHubのmainが連携しています。公開承認後、型・lint・buildと画面を確認してmainへpushします。連絡先の公開は別途確認します。

依存関係は`package-lock.json`で固定し、`npm ci`でインストールします。Next.js内包分も含めてPostCSSを8.5.23へ揃えています。
